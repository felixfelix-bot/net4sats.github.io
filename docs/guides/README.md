# net4sats — Operator Guides

Step-by-step guides for setting up and operating a net4sats router.

## Guides

| Guide | What it covers |
|-------|---------------|
| [Setup with conwrt](./setup-with-conwrt.md) | Install conwrt, point it at a router, run the net4sats flow, verify deployment |
| [Admin panel guide](./admin-panel-guide.md) | Access the admin dashboard, navigate all pages, configure pricing/mints/WiFi/wallet/identity |

## Quick start

1. Flash your router to stock OpenWrt (see the conwrt guide for flashing).
2. Follow the [conwrt setup guide](./setup-with-conwrt.md) to deploy net4sats.
3. Open the [admin panel guide](./admin-panel-guide.md) to configure and manage.
