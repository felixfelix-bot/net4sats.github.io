net4sats

TollGate on your router — metered internet, paid per use.

Install

git clone https://github.com/net4sats/installer
cd installer && sh install.sh

Or, piping straight to a shell:

curl -sL https://raw.githubusercontent.com/net4sats/installer/main/install.sh \\
  | N4S_REPO_SLUG=net4sats/installer sh

N4S_REPO_SLUG is required when piping because the script carries no brand literal — the brand is data. From a clone no variable is needed.

What this does

Deploys the upstream TollGate stack to a supported OpenWrt router, branded as net4sats. The wizard runs on this machine and talks to the router over your network.

Supported routers

The upstream feed publishes both .apk (OpenWrt 25.12) and .ipk (OpenWrt 24.10) for the aarch64_cortex-a53 / mediatek-filogic target.

RouterStatus
GL.iNet GL-MT3000validated — in-place upgrade verified
GL.iNet GL-MT6000validated — in-place upgrade verified
COMFAST CF-WR632AXasset published, not yet installed on hardware

Any other device on the same target with enough flash should work, but only the rows above have been checked. If your router is not listed, do not flash it blind.
